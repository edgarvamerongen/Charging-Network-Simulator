# Charging Network Simulator (CNS)

NRG2FLY's planning tool for electric-aircraft charging demand: pick an
aircraft, a route and a charger; the simulator sizes the energy, charge
time and per-airport peak load, and exports a PDF / XLSX plan.

- Run, test, conventions: `CLAUDE.md`
- Deploy and the Notion catalog sync: `deploy/README.md`
- Catalog design record: `NOTION_CATALOG_PLAN.md`
